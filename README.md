## Prerequisites

Install OCaml and Dune. This starter was checked with OCaml 5.3.0 and Dune
3.24.2; the project requires Dune 3.0 or newer.

## Build, run, and test

```sh
dune build
dune exec bin/main.exe
dune test
```

The executable currently prints a placeholder message. The startup test checks
that the executable runs; add meaningful tests for the application's behavior as
it is developed.

## Team checklist

- Agree on an application and scope, and define how its parts interact.
- Agree on responsibilities, interfaces, and how the team will review AI-assisted work.
- Give implementation modules documented `.mli` interfaces (except the main
  driver and tests), and keep important behavior separate from the interface.
- Record authors and sources in `AUTHORS.md` and document design decisions.
- Add automated and, where appropriate, manual checks; document installation
  and use for someone outside the team.
